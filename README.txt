FIX DECIMALES - FACTURA DE OBRA

Permite escribir el monto con:
26534914,20
o
26534914.20

Se aplica tanto a:
- Nueva factura
- Editar factura

Aplicar desde la raíz:
.\APLICAR.ps1

Luego:
git diff
git status
git add .
git commit -m "Permitir decimales en monto de factura"
git push

Solo requiere Vercel.
